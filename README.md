# 🏢 ACEMA Ingeniería - Sistema de Gestión de Usuarios

Sistema web de gestión de usuarios desarrollado con React, TypeScript y Tailwind CSS. Consume la API de RandomUser para demostración de funcionalidades CRUD, autenticación, y manejo de estado global.

## ✨ Características

- ✅ **Autenticación** - Sistema de login con validación de credenciales
- ✅ **Dashboard Interactivo** - Visualización de usuarios en tarjetas responsivas
- ✅ **CRUD Completo** - Crear, leer, actualizar y eliminar usuarios
- ✅ **Búsqueda en Tiempo Real** - Filtrado por nombre y email
- ✅ **Paginación** - Navegación de 10 usuarios por página
- ✅ **Rutas Protegidas** - Acceso restringido sin autenticación
- ✅ **Persistencia de Datos** - LocalStorage para mantener estado entre sesiones
- ✅ **Diseño Responsivo** - Optimizado para móvil, tablet y desktop
- ✅ **TypeScript** - Tipado estático para mayor seguridad
- ✅ **Manejo de Estado Global** - Context API para gestión eficiente

## 🛠️ Tecnologías

### Frontend
- **React** 18.2.0 - Librería de UI
- **TypeScript** 5.2.2 - Superset tipado de JavaScript
- **Vite** 5.0.8 - Build tool y dev server
- **React Router DOM** 6.21.1 - Enrutamiento de la aplicación
- **Tailwind CSS** 3.4.0 - Framework de estilos utility-first

### Herramientas de Desarrollo
- **ESLint** - Linter para JavaScript/TypeScript
- **PostCSS** - Procesamiento de CSS
- **Autoprefixer** - Prefijos CSS automáticos

### API Externa
- **RandomUser API** v0.8 - Generación de usuarios aleatorios
